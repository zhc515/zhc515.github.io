Title: An estimate using auxiliary Monge-Ampère equation

Abstract: We will discuss the technique developed by Guo-Phong-Song-Sturm, using an auxiliary Monge-Ampère equation to establish \\(L^\infty\\) estimates of harmonic functions on compact Kähler manifolds, with very mild assumptions. The argument is interesting since it solves a problem in linear PDE using fully nonlinear PDE. If time permits, we may discuss some possible extensions.
